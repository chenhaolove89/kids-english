仓库：E:\kids-english。目标：按 docs/learning-platform-plan.md 实现第一阶段可运行的课程目录与本地学习闭环。推理摘要和交付说明使用中文。

先读取仓库指令、README、架构文档及 git diff，保护现有修改。当前 docs 与 .gitignore 修改是已确认的规划和凭据保护，不要覆盖。

## 实施范围

1. 新建统一课程目录、活动模型及旧内容适配器。阶段包括启蒙和一至六年级，难度与年级独立。用现有真实资源接入英语、语文、数学各至少一条课程路径。不得伪造高年级完整覆盖，筹备课程禁用开始按钮；保留旧三科浏览入口。
2. 首页增加阶段选择、课程入口、继续学习与本机学习摘要。沿用已有儿童友好设计，确保窄屏、平板、桌面可用。继续学习须恢复到真实课程和位置，不只是返回科目页。
3. 提取纯函数及服务层，封装 uni 存储；实现带 schemaVersion 的进度与作答记录，处理空数据、损坏数据、写入失败。第一阶段单档案，避免提前构建账号后台。
4. 在现有学习、挑战、数学页面接入 lessonId/sessionId；没有新参数的旧入口仍正常。分别记录首次正确、最终完成与错题，避免重复点击重复计数。修正首次错后重试最终仍满分所造成的统计歧义，页面明确区分指标。保存中断进度，退出清理定时器；数学参数越界安全回退。动态数学题恢复时保存题目快照，避免重生成导致记录错配。
5. 内容目录有稳定 ID 和引用校验；生成的 words.json、hanzi.json、audio-volumes.json 不手工编辑，不重新生成整个媒体库。
6. 暂不重写现有 H5 音频，只隔离新增业务对平台的依赖。音频失败不得使作答流程永久卡住。暂不新增小程序/App 构建目标，不声称跨端已验证。
